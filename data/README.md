# Data

This folder holds the raw data of the project.

- `raw/` — the original files from data.gov.il. **Do not edit these files.**
- Any cleaned or changed data should be written to `data/processed/`,
  which is not tracked by git.

Source: https://data.gov.il/datasets/ministry-health/nutrition-database
Publisher: Israeli Ministry of Health.
Downloaded with the public CKAN API on 2026-10-20.

See the main `README.md` for the list of files, how they connect,
and how the class label is built from the food code.
